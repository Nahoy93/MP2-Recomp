# Mario Party 2

Det här repot innehåller två saker:

- **Dekompileringen** av Mario Party 2 (N64), forkad från
  [mariopartyrd/marioparty2](https://github.com/mariopartyrd/marioparty2):
  `src/`, `include/`, `marioparty2.yaml`, `Makefile` m.m. Bygget här ger
  tillbaka originalets N64-ROM.
- **PC-porten** *Mario Party 2: Recompiled* för Windows och Linux, i
  [`recomp/`](recomp/). Börja med [recomp/BYGGA.md](recomp/BYGGA.md).

Inget av detta innehåller speldata. Du behöver en egen ROM av Mario Party 2 (USA).
